<analysis>**original_problem_statement:**
The user's goal is to build a full-stack application for Property Managers and Tenants. The core workflow involves a tenant reporting an issue, which the property manager then reviews and forwards to a service provider for quoting and completion.

Initially, the user requested a migration from MongoDB to SQLite, which was completed. The current focus is on building out the primary features based on a provided flowchart and mockups.

**Key features requested and implemented/in-progress:**
1.  **User Roles & Linking:** Separate dashboards for Tenants, Property Managers, and Service Providers. A key feature is the ability for a Tenant to link to a Property Manager using a unique code.
2.  **AI-Powered Issue Reporting:** Tenants report issues via an interface that should start with a simple prompt, use an AI (Gemini) to process the initial description, and then present a structured form for more details.
3.  **End-to-End Issue Resolution Flow:**
    *   Tenant reports an issue.
    *   The issue appears on the Property Manager's dashboard.
    *   The PM can send the issue as an order to a Service Provider.
    *   The Service Provider submits a quote.
    *   The PM approves/rejects the quote.
    *   The Service Provider completes the work.
    *   The PM marks the issue as resolved.
4.  **Property Tracking:** When a tenant joins a PM, the property address they provide should be captured and displayed on the PM's dashboard.

**User's preferred language**: English
