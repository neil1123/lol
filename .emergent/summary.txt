<product_requirements>
The Doord application is a mobile-responsive marketplace linking homeowners and service providers, aiming to streamline service discovery, booking, and management. Core functionalities include data migration to MongoDB Atlas, JWT authentication, real-time messaging, dynamic service management for providers, and comprehensive provider profile editing with live previews. The application emphasizes UI/UX consistency, mobile responsiveness, and robust deployment.

Recently implemented and refined features:
1.  **Quotation Display Fix**: Correctly display specific quotation amounts instead of budget ranges on both homeowner and provider quotation views.
2.  **New User Bases**:
    *   **Property Managers (PMs)**: Have a dashboard similar to homeowners (without messages sidebar), a dedicated landing page with login/signup, and can approve/deny tenant service booking requests. They can also directly book services for properties. PMs can onboard tenants via a specific code.
    *   **Tenants**: Can register using an optional PM code, and their experience is otherwise similar to homeowners. The key difference is that when a tenant requests a service, the provider's quotation goes directly to the tenant's associated Property Manager for approval, not the tenant. Only after PM approval is the booking confirmed.
3.  **Mobile Responsiveness**: All newly developed Property Manager and Tenant frontend components must be mobile-responsive, including navigation (e.g., hamburger menu).
</product_requirements>
